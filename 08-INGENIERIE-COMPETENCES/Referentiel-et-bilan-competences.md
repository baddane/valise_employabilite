# 🧠 INGÉNIERIE DES COMPÉTENCES — RÉFÉRENTIEL & BILAN

> Identifier, structurer et développer les compétences : construire un référentiel, réaliser un
> bilan, élaborer un plan de développement.

---

## PARTIE 1 — CONSTRUIRE UN RÉFÉRENTIEL DE COMPÉTENCES

Un référentiel décrit, pour un métier, les **compétences attendues** et leurs **niveaux**.

### Structure type

| Domaine de compétence | Compétence | Niveau attendu | Indicateur observable |
|---|---|:---:|---|
| Technique | | 1–4 | « est capable de… » |
| Technique | | | |
| Organisationnelle | | | |
| Relationnelle | | | |
| Numérique | | | |

**Échelle de niveaux :**
1. **Notions** — sait de quoi il s'agit, avec appui.
2. **Application** — réalise des tâches simples en autonomie partielle.
3. **Maîtrise** — autonome sur des situations courantes.
4. **Expertise** — gère les cas complexes, transmet.

---

## PARTIE 2 — LE BILAN DE COMPÉTENCES (structure)

### Phase 1 — Préliminaire
- Analyser la demande et le besoin.
- Définir les objectifs du bilan.
- Poser le cadre (confidentialité, engagement).

### Phase 2 — Investigation
- Explorer parcours, compétences, intérêts, valeurs, personnalité.
- Identifier compétences techniques, transférables, comportementales.
- Confronter aux réalités du marché (module 02).

### Phase 3 — Conclusion
- Formaliser le **projet professionnel**.
- Identifier les **écarts** et besoins de formation.
- Bâtir le **plan d'action**.

**Livrable :** document de synthèse (atouts, projet, plan d'action).
