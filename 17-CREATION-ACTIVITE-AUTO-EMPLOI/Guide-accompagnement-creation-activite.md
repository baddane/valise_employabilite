# 🚀 GUIDE D'ACCOMPAGNEMENT À LA CRÉATION D'ACTIVITÉ & À L'AUTO-EMPLOI

> Pour une partie des chercheurs d'emploi, la meilleure voie est de **créer son propre emploi** :
> auto-entrepreneur, petite entreprise, coopérative. Le rôle du conseiller n'est pas de faire le
> projet à la place de la personne, mais de **vérifier la faisabilité, structurer, orienter vers les
> bons financements et suivre après la création**.

---

## 1. Le parcours en 5 étapes

| Étape | Objectif | Outil | Durée indicative |
|:---:|---|---|:---:|
| **1. Accueil du projet** | Comprendre l'idée et la motivation | Diagnostic du porteur (§2) | 1 entretien |
| **2. Test de l'idée** | Vérifier qu'il existe des clients prêts à payer | Grille de faisabilité (§3) + enquête terrain | 2 à 4 semaines |
| **3. Modèle économique** | Décrire comment l'activité gagne de l'argent | Canevas simplifié (§4) | 2 à 4 semaines |
| **4. Chiffrage & financement** | Besoins de départ, seuil de rentabilité, sources de financement | Plan de financement (§5) | 1 à 2 mois |
| **5. Création & suivi** | Choisir le statut, lancer, sécuriser les premiers mois | Choix du statut (§6) + suivi (§7) | 12 mois de suivi |

---

## 2. Diagnostic du porteur de projet

| Question | Réponse | 🟢 / 🟠 / 🔴 |
|---|---|:---:|
| Pourquoi voulez-vous créer ? (choix ou faute d'emploi ?) | | |
| Avez-vous une expérience dans ce métier ou ce secteur ? | | |
| Avez-vous déjà vendu ce produit / service (même de façon informelle) ? | | |
| Combien de temps pouvez-vous tenir sans revenu de l'activité ? | | |
| Quel apport pouvez-vous mobiliser (argent, matériel, local) ? | | |
| Votre entourage vous soutient-il ? | | |
| Êtes-vous prêt(e) à gérer (clients, comptes, démarches) ? | | |

**Lecture :** plusieurs 🔴 sur l'expérience, la vente ou la trésorerie → **tester d'abord** (vente à
petite échelle, salariat dans le secteur, formation) avant d'engager de l'argent.

> 💡 Une création « par défaut d'emploi » n'est pas à refuser, mais elle doit être **testée à petite
> échelle** et accompagnée de près : les risques d'échec et d'endettement sont plus élevés.

---

## 3. Grille de faisabilité de l'idée

| Critère | Question | Constat terrain |
|---|---|---|
| **Clients** | Qui va acheter ? Combien sont-ils dans ma zone ? | |
| **Besoin** | Pourquoi achèteraient-ils chez moi ? | |
| **Concurrence** | Qui vend déjà la même chose ? À quel prix ? | |
| **Prix** | Quel prix les clients sont-ils prêts à payer ? | |
| **Compétences** | Est-ce que je sais produire / rendre ce service avec qualité ? | |
| **Moyens** | Local, matériel, fournisseurs, autorisations nécessaires ? | |
| **Réglementation** | Autorisation, hygiène, diplôme exigé ? | |

**Enquête terrain minimale avant de continuer :** interroger **au moins 10 clients potentiels** et
**3 professionnels** du secteur (même méthode que l'enquête métier, module 03).

## 4. Canevas simplifié du modèle économique

> Inspiré du *Business Model Canvas* (Osterwalder & Pigneur, 2010), en version courte.

| Bloc | Réponse du porteur |
|---|---|
| **Mes clients** (qui ?) | |
| **Ce que je leur apporte** (quelle solution, quel avantage ?) | |
| **Comment je les atteins** (bouche-à-oreille, réseaux sociaux, boutique, marchés…) | |
| **Ce que je vends et à quel prix** | |
| **Ce dont j'ai besoin** (matériel, local, stock, compétences) | |
| **Mes partenaires** (fournisseurs, coopérative, famille…) | |
| **Mes coûts principaux** (achats, loyer, transport, charges) | |

## 5. Plan de financement et seuil de rentabilité (version simple)

**Besoins de départ**

| Besoins | Montant (DH) | Ressources | Montant (DH) |
|---|---:|---|---:|
| Matériel / équipement | | Apport personnel | |
| Stock de départ | | Famille / proches | |
| Aménagement du local | | Prêt (programme public, banque, microcrédit) | |
| Démarches, frais de création | | Subvention / appui (INDH, autre) | |
| Trésorerie de sécurité (3 mois de charges) | | | |
| **Total besoins** | | **Total ressources** | |

**Seuil de rentabilité mensuel**
```
Charges fixes du mois (loyer, transport, remboursement, rémunération minimale) = A
Marge par vente (prix de vente – coût d'achat ou de production)                  = B
Nombre de ventes nécessaires par mois pour couvrir les charges                   = A ÷ B
```
> Si le nombre de ventes nécessaires paraît irréaliste pour la zone, **revoir le projet** (prix, coûts, clients).

**Sources de financement à explorer** : voir module 11, §6 (programmes publics via les banques,
INDH, microcrédit, Maroc PME, CRI). Toujours vérifier les conditions **en vigueur**.

## 6. Choisir un statut (repères)

| Statut | Pour qui | Points clés | À vérifier |
|---|---|---|---|
| **Auto-entrepreneur** (loi n° 114-13) | Petite activité individuelle | Démarches simplifiées, fiscalité allégée, couverture sociale | Plafonds de chiffre d'affaires, activités éligibles |
| **Entreprise individuelle** | Activité individuelle plus importante | Responsabilité sur les biens personnels | Régime fiscal |
| **SARL / SARL à associé unique** | Projet avec investissement, associés, embauches | Responsabilité limitée aux apports | Formalités (CRI), comptabilité |
| **Coopérative** | Projet collectif (femmes, agriculture, artisanat) | Gouvernance collective, accompagnement dédié | Nombre minimum de membres, organisme d'accompagnement |

> Orienter vers le **CRI** ou l'organisme compétent pour les formalités ; le conseiller ne remplace pas un comptable.

---

## 7. Suivi après la création (les 12 premiers mois sont décisifs)

| Échéance | Points à vérifier |
|---|---|
| **M+1** | Démarrage réel ? Premiers clients ? Difficultés administratives ? |
| **M+3** | Ventes vs prévisions, trésorerie, remboursements tenus ? |
| **M+6** | Seuil de rentabilité atteint ? Besoin de formation (gestion, vente, numérique) ? |
| **M+12** | Activité pérenne ? Revenu du créateur ? Embauches ? |

**Signaux d'alerte :** ventes très en dessous du prévu 2 mois de suite · retards de remboursement ·
créateur qui ne se rémunère pas · isolement. → Réagir vite : conseil de gestion, réseau de parrainage,
réorientation (reprise d'emploi salarié) sans vivre l'arrêt comme un échec.
