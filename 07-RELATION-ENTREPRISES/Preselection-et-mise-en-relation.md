# 🎯 PRÉSÉLECTION, MISE EN RELATION & JOB DATING

> Le moment où l'agence crée de la valeur pour **les deux parties** : présenter à l'employeur des
> candidats réellement adaptés, et au candidat des offres qui correspondent à son projet.
> Une mauvaise mise en relation coûte cher : employeur déçu, candidat découragé, rupture précoce.

---

## 1. Le processus en 6 étapes

```
1. OFFRE QUALIFIÉE      → Fiche d'analyse de poste remplie avec l'employeur (Fiche-analyse-poste.md)
2. CONTRÔLE DE L'OFFRE  → Offre légale et non discriminatoire (§2)
3. SOURCING             → Portefeuille de l'agence + plateforme + ateliers + partenaires
4. PRÉSÉLECTION         → Grille de correspondance candidat ↔ poste (§3) + entretien court
5. PRÉSENTATION         → Accord du candidat, envoi des profils, préparation à l'entretien (§4)
6. RETOUR & SUIVI       → Retour employeur sous 7 jours, réponse à chaque candidat, suivi si embauche
```

**Délai cible :** premiers profils envoyés à l'employeur sous **5 jours ouvrés** après la qualification de l'offre.

---

## 2. Contrôle de l'offre : légalité et non-discrimination

Avant toute diffusion, vérifier :

☐ L'intitulé et les missions sont clairs et réels
☐ La rémunération respecte le **salaire minimum légal** en vigueur
☐ Le type de contrat est cohérent avec le poste (voir module 11)
☐ **Aucun critère discriminatoire** : le Code du travail (art. 9) interdit les discriminations fondées
  notamment sur la race, la couleur, le sexe, le handicap, la situation conjugale, la religion, l'opinion
  politique, l'affiliation syndicale, l'origine nationale ou sociale. Par bonne pratique, écarter aussi
  les critères d'âge ou d'apparence non justifiés par le poste.
☐ Les critères demandés sont **justifiés par le poste** (ex. : permis si conduite réelle)

**Si l'employeur formule une demande discriminatoire** (« pas de femmes », « moins de 30 ans »…) :
1. Reformuler vers le besoin réel : *« Quelle compétence ou contrainte du poste se cache derrière ce critère ? »*
2. Proposer un critère objectif (ex. : « capacité à porter 20 kg » plutôt que « un homme »).
3. Si l'employeur maintient : **ne pas diffuser l'offre** avec ce critère, tracer l'échange, en informer la hiérarchie.

## 3. Grille de présélection (correspondance candidat ↔ poste)

**Offre :** ______________________  **Entreprise :** ______________________  **Date :** ____/____/______

| Critère (repris de la fiche de poste) | Poids (1–3) | Éliminatoire ? | Candidat A | Candidat B | Candidat C |
|---|:---:|:---:|:---:|:---:|:---:|
| Compétence technique n°1 | | ☐ | /4 | /4 | /4 |
| Compétence technique n°2 | | ☐ | /4 | /4 | /4 |
| Expérience / formation | | ☐ | /4 | /4 | /4 |
| Soft skill clé du poste | | ☐ | /4 | /4 | /4 |
| Mobilité / horaires compatibles | | ☐ | /4 | /4 | /4 |
| Motivation pour ce poste précis | | ☐ | /4 | /4 | /4 |
| **Score pondéré** | | | | | |

**Règles :**
- Un critère éliminatoire non rempli = candidat non présenté, quel que soit le score.
- Présenter en priorité les candidats **au-dessus de 70 %** du score maximal ; 3 à 5 profils par poste.
- Vérifier la **motivation pour ce poste** par un appel court : un bon profil non motivé = rupture probable.
- **Égalité des chances :** à compétences égales, veiller à ce que les publics prioritaires ne soient pas
  systématiquement écartés (suivre la part de femmes, de jeunes sans diplôme, de personnes handicapées présentées).

**Entretien court de présélection (15 min, questions comportementales) :**
1. *« Racontez-moi une situation où vous avez [compétence clé du poste]. »* (réponse STAR attendue)
2. *« Qu'est-ce qui vous intéresse dans ce poste et cette entreprise ? »*
3. *« Les horaires sont [X], le lieu est [Y] : est-ce compatible avec votre situation ? »*
4. *« Qu'est-ce qui pourrait vous faire quitter ce poste dans les 3 premiers mois ? »*

## 4. Présentation des candidats à l'employeur

☐ **Accord du candidat** obtenu pour cette offre précise (voir consentement, module 01)
☐ CV à jour et adapté à l'offre
☐ Courte note de présentation (3 lignes : atouts, adéquation, disponibilité)
☐ Candidat préparé : entreprise, poste, lieu, heure, interlocuteur, questions probables
☐ Aides à l'embauche mobilisables signalées à l'employeur (module 11)

**Modèle de note de présentation :**
```
Candidat : [Prénom N.] — [métier]
Atouts pour le poste : [2–3 éléments concrets, ex. : 2 ans en maintenance de lignes, habilitation électrique]
Disponibilité : [date] · Mobilité : [zone] · Dispositif mobilisable : [le cas échéant]
```

> 💡 **Tout candidat présenté reçoit une réponse**, avec le motif si l'employeur l'a donné.
> Un refus expliqué devient un axe de travail du PAI ; un refus sans réponse décourage.

**Si 3 candidats de suite sont refusés pour la même offre :** revoir la fiche de poste avec l'employeur
(exigences irréalistes ? salaire hors marché ?) ou proposer une formation préalable à l'embauche.

## 6. Organiser un job dating

| Quand | Étape | Check |
|---|---|:---:|
| J-30 | Choisir 1 secteur en tension, mobiliser 3 à 8 employeurs, recueillir leurs offres (fiches de poste) | ☐ |
| J-21 | Réserver la salle, fixer le format (entretiens de 10–15 min, stands, ou speed-recruiting) | ☐ |
| J-15 | Présélectionner les candidats sur les offres réelles (grille §3), les inviter | ☐ |
| J-7 | Atelier de préparation des candidats (pitch 2 min + simulation) | ☐ |
| J-2 | Confirmer employeurs et candidats, préparer planning, badges, CV imprimés, fiches d'évaluation | ☐ |
| Jour J | Accueil, planning, fiche d'évaluation par entretien, point à chaud avec les employeurs | ☐ |
| J+7 | Collecter les décisions, répondre aux candidats, relancer les employeurs | ☐ |
| J+30 | Bilan : entretiens, embauches, satisfaction des deux parties | ☐ |

**Indicateurs d'un job dating :** employeurs présents · offres · candidats reçus · entretiens ·
embauches à J+30 · satisfaction employeurs et candidats.
